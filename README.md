# DCIT323 Lab 1 – Git and GitHub

## Assignment Overview
This repository contains my work for DCIT323 Lab 1. The assignment demonstrates the basic Git and GitHub workflow.

## Objectives
- Create a repository on GitHub.
- Clone the repository to a local computer.
- Edit and create files.
- Stage changes using Git.
- Commit changes to the repository.
- Push committed changes to GitHub.

## Git Commands Used

| Command | Purpose |
|---|---|
| `git clone` | Copies a repository to the local computer. |
| `git add .` | Stages changes for committing. |
| `git commit -m` | Saves changes in Git history. |
| `git push origin main` | Uploads committed changes to GitHub. |
